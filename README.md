## Sobre mí

Desarrollador Full Stack enfocado en aplicaciones web, APIs y automatización de procesos. Trabajo principalmente con **C# / .NET**, **TypeScript / Next.js** y **Python**, y aplico arquitectura limpia para que el código sea fácil de mantener y evolucionar.

Mi criterio de trabajo es simple: si una tarea se repite de forma manual, la convierto en una herramienta o un proceso automatizado.
